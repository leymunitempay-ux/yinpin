# 🌌 沉浸视界 · 个人网站（Python + Three.js）

一个**像戴上 VR 眼镜**的个人网站：无需任何外部素材，纯代码生成的柔和星云宇宙中悬浮着你的四个"区域灯塔"（关于我 / 足迹 / 兴趣 / 联系我）。拖动鼠标或手指即可 360° 环顾四周（VR 转头感），点击灯塔或顶部导航，镜头会**平滑飞向**对应区域并展开"全息窗口"。

> 站点内容为**通用个人主页**风格（生活 / 爱好 / 足迹，不含代码相关内容）。
> 方案细节见《个人网站设计方案.md》；上线发布见 **《上线部署指南.md》**（国内访客的免备案静态托管与服务器备案两条路线）；"改了文字没反应"见 **《文字修改指南.md》**。

## 🚀 快速开始

### 方式一：标准环境（有外网）

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows
pip install -r requirements.txt
python server.py                  # → http://127.0.0.1:8090
```

### 方式二：无外网 / 受限环境

依赖已可用 `fetch_deps.py` 从 PyPI 拉取并装入项目内 `.deps/`（`server.py` 会自动加载）：

```bash
python fetch_deps.py   # 首次运行即可（当前项目已装好，可跳过）
python server.py
```

打开浏览器访问 **http://127.0.0.1:8090**，点击「戴上虚拟眼镜，进入」。

## 🎮 操作指南

- **环视**：按住鼠标左键拖动 / 手指滑动（像转动头部）
- **缩放**：滚轮 / 双指捏合
- **切换区域**：顶部导航、点击空间中的发光灯塔，或按数字键 `1`~`5`
- **关闭窗口**：窗口内「✕ 关闭 / ⌂ 回大厅」或 `Esc`
- **工具栏**：🔊 音效 ｜ 🧘 安静模式 ｜ ⛶ 全屏
- 悬停可点击的 3D 对象时光标会变为手型

## 📁 项目结构

```
个人网站/
├─ server.py              # FastAPI 后端（静态托管 + /api 接口）
├─ fetch_deps.py          # 无外网环境依赖引导脚本
├─ requirements.txt       # 标准环境依赖
├─ static/
│  ├─ index.html          # 单页入口
│  ├─ css/style.css       # 星空玻璃拟态主题
│  ├─ js/
│  │  ├─ scene.js         # Three.js 3D 世界（星空/灯塔/镜头飞行）
│  │  ├─ app.js           # 站点交互（仪式/导航/窗口/表单/音效）
│  │  └─ vendor/three.module.js   # 本地化的 Three.js（r160）
│  └─ data/profile.json   # ⭐ 你的全部内容配置
├─ messages/              # 联系表单留言落盘目录
└─ .deps/                 # 离线依赖（可选，由 fetch_deps.py 生成）
```

## 🛠 内容管理后台（不需要写代码）

启动 `python server.py` 后，浏览器打开 **http://127.0.0.1:8090/admin** 即可用表单可视化增改网站内容：

- 基本信息（名字/头衔/简介/邮箱/标语）· 🌊 足迹（可**从电脑上传照片**）· ⏳ 时间线
- 🧡 兴趣 · 🔗 社交链接 · 🌤 每日一言 · 🎂 特别日子
- 🎛 **功能设置**：想停用哪个功能直接取消勾选（流星/罗盘/心情按钮/每日一言/星尘特效…），不用改代码

改完点「💾 保存」，回网站刷新即生效。

**安全（登录）**：管理后台现在需要登录——
- 本机打开 `/admin` 会出现登录页，点「🖥 本机免密进入」即可（仅限本机，浏览器会话 12 小时内免重复登录）；
- 若设置了环境变量 `ADMIN_KEY=你的密码`，本机与远程都必须在登录页输入该密码；
- 未显式设置时服务器会自动生成本地密钥文件 `data/.admin_secret`（不要外传，也别把它上传到公开仓库）；
- 所有管理接口都要求会话令牌，并拒绝跨站（Origin）请求，陌生网页无法偷偷修改你的内容。

## ✏️ 换成你的内容

一般内容都在 **`static/data/profile.json`**，推荐直接在上面的后台里改（无需碰代码）；手改时注意字段格式：

- `owner`：姓名 / 头衔 / 简介 / 所在城市 / 邮箱（页面文案均为通用生活风格）
- `timeline`：关于页的时间线（人生节点、重要时刻）
- `moments`：足迹卡片（支持 `title / summary / tags / photo / photos / link / emoji / color`，`photo` 填图片直链显示照片，留空显示 emoji）
- `interests`：兴趣清单 + 浓度（0–100）
- `socials`：社交链接（如 邮箱 / 小红书 / 微信，icon 可用 emoji）
- `quotes`：每日一言（每行一句）
- `specialDays`：生日/纪念日（格式 `{"month":1,"day":1,"type":"birthday","emoji":"🎂","text":"…"}`）
- `config`：功能开关（后台"功能设置"卡片可改）

> 📖 **"我改了文字没反应"？** 本站正文是数据驱动的——请在 `profile.json` 里改，而不是 HTML。哪些文字在哪个文件、怎么让修改生效，详见 **《文字修改指南.md》**。

> 纯静态托管（如 Vercel / GitHub Pages）同样可用：上传 `static/` 即可浏览全站；
> 联系表单在无后端时会提示启动 `python server.py`（或接入 Formspree 等第三方服务）。
