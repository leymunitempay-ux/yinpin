# ✏️ 文字修改指南（改哪里才有效）

**常见困惑**："我改了 `static/index.html` 里的文字，刷新后怎么没变化？"

因为本站是"**数据驱动**"结构：页面上的大部分文字**不是写死在 HTML 里**，而是运行时由 `static/js/app.js` 读取 **`static/data/profile.json`** 后注入的。HTML 里那些只是占位符，一加载就会被 JSON 覆盖。

> ✅ 记住一句话：**改"人话内容" → 改 `static/data/profile.json`；只有改"按钮布局/固定功能词"才需要碰 HTML 或 JS。**

## 🔄 怎么让修改生效

1. 改完 `profile.json` / `index.html` 后**保存文件**；
2. 浏览器里**强制刷新**：`Ctrl + F5`（手机：下拉刷新 / 清除缓存刷新）；
3. 若你用的是 `python server.py`，改静态文件**无需重启服务**（页面直接读磁盘）。

## 🖼 给"足迹"配图

每个足迹可带一张照片（`photo` 字段，网页图床链接即可）：

```json
{
  "id": "m-1",
  "title": "去看海",
  "emoji": "🌊",
  "color": "#8fd3ff",
  "summary": "……",
  "tags": ["海边"],
  "photo": "https://你的图床/xx.jpg",   ← 加这一行；留空或不写 = 用 emoji 渐变卡片
  "link": ""
}
```

> 提示：可以用任意图片直链（图床 / 微信公众号图 / GitHub 仓库图片等）。图片加载失败时卡片会自动回退为 emoji 风格，不会破版。

## 📁 相关文件速查
