# 🚀 上线部署指南（针对：国内访客 · 从零开始 · 保留站内留言）

> 目标：让朋友能用一个**网址**打开你的沉浸空间。
> 先记住两个结论：
> 1. 想让**国内稳定、体验好**，最终答案是「域名 + 国内服务器 + 备案」——但这需要实名与等待；
> 2. 想**今天就有一个可分享的链接**，走免备案静态托管即可——速度一般但零成本。

---

## 一、两条路线，怎么选

| | 路线 A：免备案 · 快速上线 | 路线 B：国内正式版 |
| --- | --- | --- |
| 适合 | 先拿到链接、验证想法 | 长期稳定给国内访客 |
| 成本 | ¥0（免费额度） | 域名 ≈ ¥60–100/年 + 轻量服务器 ≈ ¥100 上下/年（首年促销） |
| 耗时 | 1 小时（含注册实名） | 备案约 1–3 周 + 1 天部署 |
| 国内速度 | 一般（看运营商，可能偏慢） | 快而稳 |
| 站内留言 | 用第三方表单服务（Formspree 等）转发到你邮箱 | 保留现有 FastAPI 后端，留言原样落盘 |
| 备案 | 不需要 | 需要（服务器在国内时） |

> 💡 **建议**：先走 **路线 A** 拿到链接试运营；同时着手 **路线 B**（域名、服务器、备案）作为最终形态。两条路线内容文件完全一样，切换只差"表单配置"一行。

## 二、路线 A：静态托管 + 第三方留言（今天上线）

### 第 1 步：注册账号（任选其一）
- **Gitee 码云**（国内访问最快）：https://gitee.com 注册并完成**实名认证**（个人页头像菜单 → 设置 → 实名认证）。Pages 服务要求实名。
- **Cloudflare Pages**（全球）：https://dash.cloudflare.com 注册（邮箱即可）。

### 第 2 步：上传网站（取 `static/` 文件夹里的全部内容）
- **Gitee**：新建仓库（公开）→ 网页端"文件 → 上传文件"或克隆后 git push → 仓库页面「服务 → Gitee Pages」→ 选择分支 → 启动（首次需审核，一般几小时～1 天）。
- **Cloudflare Pages**：登录后 Workers & Pages → Create → **Direct Upload** → 把 `static/` 里所有文件拖入上传（项目名如 `myspace`）→ 得到网址 `https://myspace.pages.dev`。
- 不推荐 GitHub Pages 作为国内主访问入口（国内不稳定）。

### 第 3 步：配置站内留言（转发到你邮箱）
1. 注册 **Formspree**（https://formspree.io，邮箱注册即可）；
2. 新建一个 Form，会得到一个表单地址：`https://formspree.io/f/xxxxxx`；
3. 打开 `static/data/profile.json`，把该地址填入：

```json
"site": {
  "brand": "沉浸视界",
  "motto": "……",
  "formEndpoint": "https://formspree.io/f/xxxxxx"
}
```

4. 重新上传 `profile.json`（或整站）。此后访客在"联系"窗口填表 → Formspree 转发到你的邮箱（免费 50 条/月）。
5. 想更贴合国内网络，可用 **EmailJS**（https://www.emailjs.com）替代，配置方式同理（拿到的是 http 接口地址）。

> 没配置 `formEndpoint` 时，网页仍会尝试请求本机 `/api/contact`——纯静态托管下会提示"留言通道暂未就绪"，不影响其它功能。

### 第 4 步：绑定自己的域名（可选，买了域名后）
- Gitee：Pages 设置里填域名 → 去域名商做 **CNAME** 解析到 `gitee.io` 对应地址；
- Cloudflare：同名域名加到 Cloudflare 托管 DNS，然后 Pages 自定义域填域名即可（自带 HTTPS）。

## 三、路线 B：国内稳定正式版（域名 + 服务器 + 备案）

### 第 1 步：买域名（约 ¥60–100/年）
- 阿里云万网 / 腾讯云 DNSPod：搜一个短好记的 `.com/.cn`。**`.cn` 备案更常见**。
- 购买后完成实名认证（身份证）。

### 第 2 步：买国内轻量服务器（促销约 ¥100/年）
- 阿里云"轻量应用服务器" / 腾讯云"轻量应用服务器"，选 **2 核 2G** 及以上、系统 **Ubuntu 22.04 / Debian 12**、地域任意大陆节点。
- ⚠️ 大陆服务器绑定域名对外提供 Web 服务**必须 ICP 备案**（免费）。

### 第 3 步：ICP 备案（免费，约 1–3 周）
- 在你买服务器的平台（阿里云/腾讯云）控制台 → 备案 → 按向导填信息、上传身份证、人脸核验。
- 等待管局审核通过后，把服务器公网 IP 用 A 记录解析到你的域名。

### 第 4 步：部署网站（全程约 1 小时）
在你的电脑上确认能连上服务器后，按顺序执行（SSH 工具：Windows 自带 PowerShell / 或 Termius）：

```bash
# 1) 安装 Python 与依赖（服务器有外网，直接用 pip，不要复制本机 .deps）
sudo apt update && sudo apt install -y python3 python3-venv nginx
python3 -m venv /opt/myspace/venv

# 2) 上传项目：把 个人网站 目录里的 server.py、static/、requirements.txt 传到服务器 /opt/myspace/
#    （可用 scp，或先 git 推送再在服务器 git clone）
scp -r server.py static requirements.txt user@你的服务器IP:/opt/myspace/

# 3) 安装依赖并试运行
cd /opt/myspace
/opt/myspace/venv/bin/pip install -r requirements.txt
/opt/myspace/venv/bin/python server.py     # 看到 http://127.0.0.1:8090 即成功，Ctrl+C 停止

# 4) 配置 systemd 常驻运行
sudo tee /etc/systemd/system/myspace.service > /dev/null <<'EOF'
[Unit]
Description=Myspace site
After=network.target

[Service]
WorkingDirectory=/opt/myspace
ExecStart=/opt/myspace/venv/bin/python /opt/myspace/server.py
Environment=PORT=8090
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable --now myspace

# 5) nginx 反向代理 + 免费 HTTPS
sudo tee /etc/nginx/sites-available/myspace > /dev/null <<'EOF'
server {
    listen 80;
    server_name 你的域名.com;
    location / { proxy_pass http://127.0.0.1:8090; proxy_set_header Host $host; }
}
EOF
sudo ln -s /etc/nginx/sites-available/myspace /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# HTTPS（Let's Encrypt 免费证书）
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名.com
```

> 国内服务器访问 Let's Encrypt 域名接口偶尔超时，失败时多试几次或换 acme 镜像。成功后即可用 `https://你的域名.com` 访问；留言直接进服务器 `messages/` 目录，可用 `tail -f messages/*.json` 查看。

## 四、上线前必做：把"占位内容"换成你自己

- 文字：全部真实信息改在 `static/data/profile.json`（见 **《文字修改指南.md》**）；
- 照片：建议把照片放进 `static/img/`（已预留该目录），`photo` 字段填相对路径如 `"img/海边.jpg"`——**随站部署、国内最稳、不受图床影响**；用外链图床需确认国内可达；
- 邮箱：把 `owner.email`、`socials` 换成真实邮箱。

## 六、常见问题

| 问题 | 处理 |
| --- | --- |
| 改完内容没变化 | 见《文字修改指南》+ 强制刷新 `Ctrl+F5`；或直接用它 **http://127.0.0.1:8090/admin** 可视化后台 |
| 访客说打不开 / 很慢 | 检查是否被墙/线路；国内主入口建议路线 B 或 Gitee Pages |
| 备案是必须的吗 | 服务器在大陆对外服务 + 域名解析 → 必须；静态托管（Pages）免备案 |
| 留言收不到 | 检查 Formspree 邮箱设置与垃圾箱；或换 EmailJS |
| 不想买服务器 | 路线 A 足够个人使用，可长期运行 |
| 服务器上想远程改内容 | 路线 B 部署后访问 `https://你的域名/admin`：若启动时设置了 `ADMIN_KEY=你的密码` 就在登录页输入它；不设置则自动生成密钥文件 `data/.admin_secret` 并默认**拒绝远程**（建议始终设置 ADMIN_KEY）。纯静态托管（路线 A）没有后台，先在本地 `python server.py` 改好后再上传一次 `data/profile.json` 与 `img/` |
