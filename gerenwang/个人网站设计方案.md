## 1. 项目概述

### 1.1 一句话定位

一个**无需 VR 头盔**、仅用鼠标/手指/手机陀螺仪就能"环顾四周、走进场景"的个人品牌网站——用户打开网站的第一秒，就像戴上了 VR 眼镜，身临其境地参观你的"虚拟空间"。

### 1.2 目标用户

| 用户 | 期望体验 |
| --- | --- |
| 潜在雇主 / 客户 | 快速、直观地了解你的能力、作品与个性 |
| 访客 / 粉丝 | 被独特的浏览体验吸引，愿意停留、探索、分享 |
| 移动端用户 | 通过手机陀螺仪"转动头部"即可环视场景 |

### 1.3 设计目标（可量化）

- 首屏 3D 场景在 **2 秒内**可交互（渐进加载：先 2D 背景后 3D 场景）
- 访客平均停留时长 ≥ 3 分钟（传统个人站约 1 分钟）
- 无需安装、无需登录、无 WebGL 也可优雅降级
- 桌面 + 移动端全覆盖，支持鼠标拖拽 / 触屏滑动 / 陀螺仪三种视角控制

## 2. 设计理念

### 2.1 核心概念：「一镜到底的虚拟漫游」

整站不是多个独立的普通页面，而是**同一个 3D 世界中的不同区域**：

```
             ┌───────────── 我的虚拟世界 ─────────────┐
             │                                        │
    [入口大厅]──────[关于我 展厅]                      │
        │                │                           │
        │                ├──[作品集 画廊]──────────  │
        │                │        │                  │
        [联系我 天台]←───┴──[技能树 数据花园]        │
             │                                        │
             └── 场景切换 = 镜头在空间中"飞"过去 ─────┘
```

页面切换不再是"刷新跳转"，而是**镜头移动（Camera Fly-through）**——与 VR 应用中的空间移动一致，形成强烈的沉浸连续感。

### 2.2 三个层次递进的沉浸度

| 层级 | 名称 | 说明 | 适用设备 |
| --- | --- | --- | --- |
| L1 | 视差沉浸 | 鼠标/陀螺仪驱动的多层视差 + 镜头微移 | 所有设备（降级兜底） |
| L2 | 第一人称沉浸 | 全景 360° 天空盒/场景内拖拽环视，接近"VR 感" | 桌面 + 移动（推荐默认） |
| L3 | 真·VR（WebXR） | 支持 Cardboard / Quest 等设备的真正 VR 模式 | 可选进阶功能 |

> **设计立场**：默认按 L2 打磨，让 90% 用户"像戴了 VR 眼镜"；L3 作为彩蛋能力保留。

## 3. 沉浸式体验设计（核心）

### 3.1 开场「睁眼」仪式（Onboarding）

模拟戴上 VR 眼镜的瞬间，建立沉浸预期：

1. **黑屏 + 淡入提示**："请戴上你的虚拟眼镜" / "Ready?"
2. **镜头从黑场中缓缓睁开（光圈收缩 / 雾散开）**，场景逐渐显形
3. 屏幕四周叠加**轻微的暗角（Vignette）与镜头畸变感**，模仿镜片边缘
4. 浮现交互提示："拖动鼠标 / 转动手机，环顾四周"
5. 一个「进入」按钮（也可直接自动进入）——参考 VR 应用"点击开始"

### 3.2 视差与镜头跟随（L1，全设备兜底）

- 鼠标移动 → 场景镜头以 `±8°` 微幅偏移 + 多层元素以不同速度平移（前景快、背景慢）
- 手机 → `deviceorientation` 陀螺仪驱动，转动手机 = 转头环视
- 所有 UI 卡片带 `3D transform` 倾斜跟随（类似苹果 Vision Pro 窗口质感）

### 3.3 360° 全景环境（L2 核心）

- 每个"房间"使用**球面全景背景（equirectangular 贴图）+ 3D 空间锚点**
- 用户拖拽 / 陀螺仪可在水平 360°、垂直 ±30° 内自由环视
- 关键内容以**悬浮在全景空间中的 3D 面板（Sprite/Plane）**呈现，仿佛站在空间中观看
- 远处有漂浮粒子（尘埃/星光）增强纵深，形成"空间就在身边"的错觉

### 3.4 镜头飞行转场（Scene Transition）

- 点击导航 → 镜头沿贝塞尔曲线**飞向目标区域**（持续 1.2s，带缓动）
- 飞行途中场景连续（粒子持续、光照渐变），绝不黑屏跳转
- 可叠加轻微的速度线 / 景深模糊强化"位移感"

### 3.5 空间化反馈

- 悬停 / 点击 3D 对象 → **空间音效**（音量随距离衰减）
- 进入不同区域 → 环境底噪切换（如：大厅=风声，作品区=电子氛围乐）
- 鼠标点击生成**涟漪/光标波纹粒子**，仿佛"手伸进空间里点了一下"
- 可选背景音乐，带静音开关（默认关，尊重用户）

### 3.6 景深与镜头光效（电影感）

- 前景虚化（Depth of Field）聚焦到用户注视的交互对象
- 光晕、眩光（Lens Flare）在光源处闪烁
- 开启 `WebGL 半透明雾` 让远处物体渐隐——放大空间纵深感

## 4. 信息架构与页面结构

### 4.1 站点地图

| 区域 | 3D 场景主题 | 内容 |
| --- | --- | --- |
| 入口大厅 | 星空穹顶下的悬浮平台 | Logo、口号、进入引导 |
| 关于我 | 温暖的展示厅（灯光墙 + 展台） | 个人简介、经历时间线、头像 |
| 作品集 | 未来感画廊（悬浮画框阵列） | 项目卡片、大图预览、GitHub 链接 |
| 技能树 | 数据花园（发光节点网络） | 技能图谱、技能熟练度 |
| 联系我 | 天台露台（夜空 + 城市远景） | 联系方式、社交媒体、邮箱表单 |

### 4.2 页面骨架（以作品集画廊为例）

```
┌──────────────────────────────────────────────┐
│  [导航浮窗] 大厅 · 关于 · 作品 · 技能 · 联系     │
│        （半透明毛玻璃，跟随镜头保持在视野内）     │
│                                              │
│   ◈ 悬浮画框1   ◈ 悬浮画框2   ◈ 悬浮画框3      │  ← 3D 空间内
│      (项目A)       (项目B)       (项目C)        │
│                                              │
│  [进入项目详情 → 镜头推近，打开 3D 详情面板]     │
└──────────────────────────────────────────────┘
```

### 4.3 内容呈现方式

- **时间线**：螺旋上升的 3D 轨迹，镜头沿轨迹平滑上移
- **作品卡片**：3D 悬浮面板，正面标题/截图、背面摘要；点按翻转
- **技能**：可交互节点图，鼠标靠近高亮并弹出说明标签
- **长文/博客**：经典 2D 阅读视图（点击进入），避免为沉浸牺牲可读性

## 5. 功能清单

### 5.1 核心功能（P0 — MVP 必须有）

- [ ] 3D 场景渲染引擎接入（Three.js），首屏场景加载与渲染
- [ ] 「睁眼」开场动画与进入引导
- [ ] 五种视角控制：鼠标拖拽环视 / 滚轮缩放 / 触屏滑动 / 陀螺仪 / WASD 平移
- [ ] 五大区域（大厅 / 关于 / 作品 / 技能 / 联系）镜头飞行切换
- [ ] 作品集数据化配置（JSON 驱动，新增作品无需改代码）
- [ ] 关于我的图文 + 时间线展示
- [ ] 技能树可视化（节点图）
- [ ] 联系表单（前端校验 + 发送接口/邮箱）
- [ ] 响应式降级：低端设备 / 无 WebGL 自动切换 2D 视差模式

### 5.2 增强功能（P1 — 体验加分层）

- [ ] 全景图自定义：更换天空盒贴图切换昼夜/季节氛围
- [ ] 鼠标轨迹粒子特效（光标拖尾星尘）
- [ ] 滚动驱动的镜头运镜（Scroll-driven camera）
- [ ] 键盘快捷键（数字键 1-5 直达各区域、F 全屏、M 静音）
- [ ] 作品 3D 展厅模式：自由走动接近作品查看大图与详情
- [ ] 双语切换（中 / EN），界面文案 i18n
- [ ] 加载进度条与分阶段资源加载（Loading 融入叙事："正在唤醒场景…"）

### 5.3 进阶/彩蛋功能（P2 — 可后续迭代）

- [ ] 真·WebXR 模式：Cardboard / Quest 头显进入（陀螺仪方案的自然延伸）
- [ ] 音效开关记忆（localStorage 保存用户偏好）
- [ ] 访客光标共游：多人实时显示光标（需后端，谨慎评估成本）
- [ ] 暗色/亮色、白天/夜晚主题一键切换
- [ ] 站点访问统计（PV / 停留时长 / 各区域热度）
- [ ] 三维小游戏彩蛋（如隐藏角落的迷你太空射击，吸引访客发现）

## 6. 交互设计规范

### 6.1 导航

| 方式 | 描述 |
| --- | --- |
| 常驻导航 | 屏幕顶部/角落毛玻璃浮窗，五个入口 + Logo，鼠标悬停显示高亮 |
| 空间导视 | 各区域悬浮"光柱/路标"3D 标识，靠近会发亮并显示区域名 |
| 手势 | 双指缩放场景、单指滑动环视；桌面右键拖拽 = 平移视角 |
| 快捷键 | `1`大厅 `2`关于 `3`作品 `4`技能 `5`联系，`Esc` 返回上一层，`M` 静音 |

### 6.2 状态反馈

- **悬停**：3D 对象轻微放大 + 发光描边 + 音效，光标变为"手"
- **点击**：对象"按下"动画（缩放 0.96）+ 涟漪扩散粒子
- **切换区域**：导航项高亮、镜头飞行、区域标题浮现
- **加载**：叙事化进度（"正在生成星空… 42%"），绝不白屏
- **错误**：空态 / 404 也放入 3D 空间（"你飘到了未知星域，点击返回大厅"）

### 6.3 动效原则

- 动画时长 ≤ 1.5s，缓动统一用 ease-in-out / ease-out-cubic
- 尊重 `prefers-reduced-motion`：检测到用户偏好后自动降级为静态 2D 模式
- 所有动效均可用「进入 2D 无障碍模式」一键关闭

## 7. 视觉与音效设计

### 7.1 视觉风格

- **主风格**：深邃科幻 × 温暖极简（深空蓝紫渐变 #0b1026 → #2a1b4d，搭配暖橙强调色）
- **质感**：发光边缘、半透明毛玻璃面板、粒子星尘、柔和辉光
- **字体**：标题用具有科技感的中英文字体（如 Orbitron / 得意黑），正文用高可读性字体
- **布局密度**：空间感优先，宁可少放元素也要留足"呼吸感"

### 7.2 场景清单（草案）

| 区域 | 环境色 | 元素 | 氛围 |
| --- | --- | --- | --- |
| 入口大厅 | 深空蓝紫 | 悬浮平台、星环、Logo 发光体 | 神秘、开场仪式感 |
| 关于我 | 暖琥珀 | 灯光长廊、翻页时光相册 | 温暖、可信赖 |
| 作品集 | 冷青 + 霓虹 | 悬浮画框阵列、流光轨道 | 前沿、专业 |
| 技能树 | 荧光绿/青 | 发光节点网络、数据粒子流 | 科技、活力 |
| 联系我 | 夜幕橙红 | 天台、远方城市灯光 | 开放、友好 |

### 7.3 音效体系

- **环境底噪**：低频空间感白噪音（风声/氛围合成器），循环、极轻
- **交互音**：悬停(短促)、点击(清脆)、切换(飞行呼啸渐弱)
- **音乐**：默认关闭，首次点击「开启音乐」时淡入
- 所有音频总开关 + 音量分级，自动暂停于页面不可见时（节省资源）

## 8. 技术选型与架构

### 8.1 技术栈建议

| 层 | 选择 | 说明 |
| --- | --- | --- |
| 框架 | React / Vue（任选，推荐 React + TypeScript） | 组件化、生态成熟 |
| 3D 引擎 | **Three.js**（或 react-three-fiber 封装） | 社区最大、文档完善 |
| WebXR | three.js WebXRManager | 真 VR 模式入口（P2） |
| 动画 | GSAP / 自研 tween | 镜头飞行、缓动控制 |
| 全景素材 | 自绘贴图 / AI 生成 equirectangular 全景 | 控制体积 |
| 构建 | Vite | 秒级 HMR、分包友好 |
| 部署 | GitHub Pages / Vercel / Cloudflare Pages | 纯前端静态站 + 第三方表单服务 |
| 表单 | Formspree / EmailJS | 免后端发信 |

### 8.2 前端架构（示意）

```
src/
├─ scenes/          # 各区域场景组件（Hall/About/Works/Skills/Contact）
├─ core/
│  ├─ renderer.ts   # WebGL 渲染器、场景、相机生命周期
│  ├─ camera.ts     # 视角控制（拖拽/陀螺仪/键盘）统一封装
│  ├─ controls.ts   # Orbit-like 自定义控制器
│  └─ transition.ts # 镜头飞行与场景切换状态机
├─ objects/         # 可复用 3D 对象（悬浮面板、光柱、粒子、光标特效）
├─ ui/              # 2D 覆盖层（导航、Loading、详情弹窗）
├─ audio/           # 音频管理器（环境音/交互音/音乐）
├─ data/            # 作品/技能/简介 JSON 数据源
├─ fallback/        # 2D 视差降级版页面
└─ i18n/            # 中英双语
```

### 8.3 数据驱动设计

作品、技能、个人信息全部外置为 JSON：

```json
{
  "works": [
    {
      "id": "project-a",
      "title": "沉浸式官网",
      "cover": "/assets/works/a.jpg",
      "gallery": ["a-1.jpg", "a-2.jpg"],
      "summary": "……",
      "tags": ["WebGL", "Three.js"],
      "link": "https://github.com/xxx"
    }
  ]
}
```

> 好处：以后更新简历/作品**不需要碰任何 3D 代码**，改 JSON 即生效。

## 9. 性能优化与兼容性

### 9.1 加载性能

- 全景图转 **WebP / AVIF**，单张 ≤ 800KB；压缩为 2K 级分辨率足够
- **渐进加载**：2D 背景 → 低模场景 → 高清贴图 → 粒子全开
- 纹理/几何体复用、按区域懒加载（进入该区域才加载其贴图）
- 首屏仅加载大厅必需资源，其余走异步 + 预加载队列
- 预算目标：首屏可交互 < 2.5s（4G 网络），Lighthouse 性能分 ≥ 85

### 9.2 运行时优化

- 像素比上限 `devicePixelRatio ≤ 2`，动态降采样
- 粒子数量随帧率自适应（掉帧时自动减半粒子与阴影）
- 页面不可见（`visibilitychange`）时暂停渲染循环与音频
- 无操作 5 分钟自动进入"待机呼吸"低功耗模式

### 9.3 兼容与降级矩阵

| 环境 | 策略 |
| --- | --- |
| 现代浏览器 + WebGL | 完整 3D 沉浸模式（L1+L2） |
| WebGL 不可用 / 极低端设备 | 2D 视差模式 + 静态卡片，内容 100% 可访问 |
| 触屏手机（无陀螺仪权限） | 滑动环视代替陀螺仪 |
| `prefers-reduced-motion` | 静态布局，禁用运镜与粒子 |
| 移动端 Safari | 处理陀螺仪权限申请（iOS 13+ 需用户授权） |

## 11. 风险与备选方案

| 风险 | 应对 |
| --- | --- |
| 沉浸模式让信息获取变慢 | 保证任何内容 ≤3 次点击可达；长文一律切 2D 阅读视图 |
| 部分用户晕 3D / 不适应 | 提供「无眩晕模式」：固定镜头 + 平面卡片；减少镜头加速 |
| WebGL 兼容 / 移动性能问题 | 坚决落实 9.3 降级矩阵，内容可访问性永远优先 |
| 陀螺仪权限获取失败 | 优雅回退到拖拽/滑动环视 |
